## 2. What the evidence says

**The bottleneck is learning to listen within one life.** Everything downstream waits on it.

- A founders' channel can exist (toy population: 43-53% reliance at u1500). It is never passed on.
- In W2 a perfect listener gains 3x food from the code, so the code is worth learning.
- A gradient learner starting from a navigator picks it up in about 8-10% of lives by age 1,000.
- A supervised probe with full data needed ~3,000 gradient steps to fit the 8-way mapping. A life gives ~480.

**Four things we now know about why it is slow.**

- **The predictive head ignores the message** (swap -0.5%, z -0.9, with coverage fixed). Its target, food in the
  7x7 view four steps ahead, is barely informed by a direction to a patch beyond view. So the self-supervised
  lever contributes nothing to listening.
- **Replay re-passes four rollouts** (`--mem 4`). More passes over the same 256 steps do not help.
- **Copying seems to carry what reliance there is.** In J2000 reliance turns down at age 1,000, exactly when
  copying stops (`--young 1000`). The teachers are scripted elders, which the real W2 run will not have.
- **Reliance is unstable within a life.** 13-20% of lives pass at some point; 6-10% at death.

**Three measurement lessons, each of which cost a round.**

- Coverage: learners heard one message per life, so every earlier null was uninformative.
- Censoring: lifespan medians were biased low until Kaplan-Meier.
- Controls: a test is only readable once a perfect listener passes >= 90% and a non-listener <= 10%.

## 4. New ideas, ranked by expected value per dollar

Each has a first test that is free or under $1, and a kill criterion. All use the frozen test `b61afb2`.

### A. Give the learner a target the message actually predicts (hindsight direction)

- **Idea:** when an agent eats, it knows where the food was relative to every place it stood on the way. Train the
  auxiliary head to predict "direction to my next meal" from the current input, labelled in hindsight from the
  agent's own trajectory. A heard sector predicts this strongly; the current target does not.
- **Why it fits:** no teacher, no named meaning. The world supplies the label. It turns every meal into dozens of
  labelled examples, which is the data rate the supervised probe needed.
- **First test (free, laptop):** the swap check on this head. If the head's error rises when the heard sector is
  rotated, the pathway is being trained. Then one all-on arm x 3 seeds on Modal (~$0.6).
- **Kill:** head uses the message (swap z > 2) but reliance stays under 15% at age 1,000.
- **Needs:** M's approval as an inborn trait (a new self-supervised drive).

### B. Fast binding instead of slow weights

- **Idea:** word learning in animals and children is one-shot binding, not thousands of gradient steps. Add a small
  plastic memory on the hearing pathway: either reward-modulated Hebbian fast weights (a three-factor rule) or a
  key-value episodic store binding "token heard" to "where food turned out to be".
- **Inheritance:** the plasticity rule's few parameters are the inherited trait and are evolved or meta-learned
  across lives. Weights are never inherited, which matches the W2 spec.
- **Why it beats the parked fast learner:** the GRU prior had to discover binding from scratch. This builds in
  the capacity to bind and learns only the rule, and it can be scored on the already calibrated learnability
  test, not the fast-learner test that will not calibrate.
- **First test (free):** unit test. With a fixed scripted speaker, does one life of experience bind >= 5 tokens?
- **Kill:** no above-chance binding after 1,000 steps in the unit test.

### C. Repair copying before it goes into W2

- **Idea:** copy in embedding space (match the elder's pre-quantisation vector) or use a soft temperature for the
  copy loss only. `TAU 0.08` makes every token policy nearly one-hot, so cross-entropy barely moves it.
- **First test (free):** a newborn reaches above-chance token agreement with a fixed elder inside its sensitive
  period. This becomes a standing unit test.
- **Why now:** copying is the only lever with a visible effect, and the W2 comm run depends on it.

### D. Make first words easy: parent calls

- **Idea:** the first speakers a newborn hears should be its provisioning parent, close by, about food that is
  near. Short distance means short credit paths, and kin reward already exists (inclusive fitness).
- **First test:** value-of-information and coverage for "parent within 3 cells, food within view of the parent".
- **Needs:** M's ruling on young-seek (staying near the parent) as an inborn trait.

### E. One shared innate trunk, individual plastic memory

- **Idea:** freeze one navigator trunk as the species' innate brain. Individuals differ only in fast weights or
  memory (idea B) and in inherited rule parameters.
- **Payoff:** a population of thousands runs as one batched forward pass. The world already steps at ~8M
  agent-steps/s; per-agent networks are what cap us at 8 agents.
- **Risk to test first:** G0 showed shared starts bias words. Rerun that control with a frozen shared trunk.

### F. Compositionality through a transmission bottleneck

- **Idea:** step 6 gave structured but holistic codes. In the literature compositional structure appears when a
  code must pass through learners who see only part of it (iterated learning). That needs transmission to work
  first, so it follows C and the learnability gate.
- **Design note:** register held-out combinations from the start, as Cam already ruled.

### G. Standing apparatus template

- Before any learner arm in any harness: coverage, positive control >= 90%, negative control <= 10%, value of
  information >= 1.5x in both forms, and a default-path identity check. This caught three bugs this week.
- Deploy the Modal-side guard as soon as M creates the secret. The Mac guard has died with the session four times.

## 5. Roadmap

Each stage has one gate. Nothing in a later stage is funded before the earlier gate passes.

| Stage | Goal | Gate | Rough cost |
|---|---|---|---|
| 0. Clean up | Confound-free dose arms; copy unit test; (e) wording | Reported | < $2 |
| 1. One-life listening | A, then B, on the frozen test | >= 50% of eligible lives rely | $5-15 |
| 2. W2 communication | Learned speakers and listeners; K / K0 / OFF arms as planned | Registered W2 bars, >= 3/5 runs | $15-30 |
| 3. Transmission | Code survives turnover with repaired copying | Newborns' code matches elders' above chance after 3 generations | $20-40 |
| 4. Structure | Iterated learning; held-out combinations | Held-out generalisation above chance and above shuffled | $30-60 |
| 5. Open world | Predators, materials, building; scale via E | New words for new things with no nudge | $50+ |
| 6. Contact | Dictionary, speak to them, read them, English through an LLM on our side | A person steers an agent with its own words | small |
| 7. Thinking in words | Language used for planning | Planners with inner speech beat those without | open |

**If stage 1 fails with both A and B:** the honest reading is that learning-to-listen needs to be evolved, not
learned in a life. The fallback is innate hearing reflexes shaped across generations, with culture limited to
which sounds mean what. That is a different and weaker claim, and it is M's call.

## 6. On "surpassing LLMs"

Stated once, plainly. Eight agents on a 96x96 grid are many orders of magnitude from a system that competes with
a large language model on general tasks, and nothing in the current evidence shortens that distance. What the
project can honestly aim to show is narrower and still worth having:

- **Grounded word learning from few exposures:** an agent binds a new signal to a new thing in tens of
  experiences, with no text. Stage 1 is the first instance of this.
- **Adapting when the world's rules change:** the generative physics hook makes this testable.
- **Cost:** continuous operation on small hardware.

**A concrete yardstick (M's decision, costs API money):** put an LLM-driven agent in the same W2 world through a
text rendering and compare it with ours on survival, speed of adapting to a rule change, and cost per life.
That turns "surpassing" into a measurement in one domain. It should wait until stage 2 passes, since before
then our agents have nothing to compare.
